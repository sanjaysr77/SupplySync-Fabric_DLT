QUICK REFERENCE - WHAT EACH PARTY DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RETAILER (You)
├─ 1. Create PO
│  └─ Go to /purchase-orders
│  └─ Click "Create PO"
│  └─ Fill: PO ID, Product, Quantity, Delivery Date
│  └─ Click "Create PO"
│
├─ 2. Monitor Status
│  └─ Check /purchase-orders
│  └─ See PENDING → APPROVED → DISPATCHED → COMPLETED
│
└─ 3. Receive Shipment
   └─ When status is DISPATCHED
   └─ Receive goods from Distributor
   └─ PO marked COMPLETED


DISTRIBUTOR
├─ 1. Receive Retailer PO
│  └─ See in /purchase-orders
│  └─ Status: PENDING
│
├─ 2. Create Linked PO to Producer
│  └─ Click "Create PO"
│  └─ Link to Retailer PO
│  └─ Send to Producer
│
├─ 3. Receive from Producer
│  └─ When Producer approves
│  └─ Receive goods
│
├─ 4. Mark Dispatch
│  └─ Click "Mark Dispatch"
│  └─ Enter dispatch date
│  └─ Ship to Retailer
│
└─ 5. Confirm Delivery
   └─ Retailer receives
   └─ PO marked COMPLETED


PRODUCER
├─ 1. Receive Distributor PO
│  └─ See in /purchase-orders
│  └─ Status: PENDING
│
├─ 2. Review & Decide
│  └─ Option A: Click "Approve"
│  └─ Option B: Click "Reject"
│
├─ 3. If Approved
│  └─ Produce goods
│  └─ Ship to Distributor
│
└─ 4. If Rejected
   └─ Distributor creates new PO
   └─ Process repeats


STATUS FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PENDING
  ↓
  ├─→ APPROVED (Producer approved)
  │     ↓
  │     DISPATCHED (Distributor shipped)
  │     ↓
  │     COMPLETED (Retailer received) ✓
  │
  └─→ REJECTED (Producer rejected)
        ↓
        (Distributor creates new PO)
        ↓
        (Process repeats)


BLOCKCHAIN RECORDING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every action is recorded on Hyperledger Fabric:

✓ PO Creation
  - Timestamp
  - Creator
  - All details
  - Immutable

✓ PO Approval/Rejection
  - Timestamp
  - Decision
  - Reason (if rejected)
  - Immutable

✓ Dispatch Marking
  - Timestamp
  - Dispatch date
  - Immutable

✓ Complete Audit Trail
  - All parties can verify
  - Cannot be altered
  - Compliance ready
